# GaugeFlow · 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 首次启用

1. 管理员创建部门及计量员、使用人员、独立质量复核员。至少两人完成报告审核，事件评估与复核分工需要留出独立人员。
2. 计量员在量具台账建档，未启用状态不可登记使用。
3. 校准审核页登记真实报告编号、机构、校准时间、结论及数据摘要或证据引用。合格报告填写有效截止日；不合格不填写。
4. 另一名具备报告审核权限的人员打开报告详情，填写意见并审核通过。合格有效量具即可登记当前使用。

## 使用与错录

使用记录中的产品、批次、检验任务和说明必须能对应实际记录。时间和使用人员由服务端确定，不能回填历史。待审校准期间暂停登记。错录由台账管理人员在使用详情带原因冲销；原始记录和后续影响快照保留。

## 超差事件

登记不合格报告立即冻结量具并建立事件，无需等候审核。事件详情显示追溯开始、结束与关联使用记录。计量员逐条分派，责任人在本人工作台进入事件，选择无影响、复检通过或产品拒收处置，附具体判断依据、复检数据及证据引用。

全部记录完成后，计量员填写系统内外追溯范围、漏记核查、产品去向与处置汇总，提交复核。没有关联使用记录也要说明范围。事件创建者和任何该事件评估者不能复核。独立复核员关闭或带意见退回；退回后可更新评估再提交。

报告被拒绝不会撤销超差冻结。需核实错误原因，保留原报告并提交时间严格递增的新报告，原事件仍须评估关闭。

## 恢复与报废

事件关闭不会自动恢复量具。所有事件关闭、失败后校准的合格报告已独立审核且有效、没有待审报告，计量员才能在量具详情带理由恢复。报废须先处理全部待审报告和未关闭事件，报废状态拒绝新的报告和使用。

有效截止日按上海时区计算，包含截止日当天。超过截止日无需后台任务即可在读取和使用校验中显示已过期。

## 导出与管理

有导出权限的人员在详情下载JSON，包含相关历史和证据。系统目录仅允许全范围管理员维护；权限目录和菜单只能调整内建项，不能通过新增名称注册未实现的接口权限。最后一个有效全范围管理员受到保护。角色权限修改即时生效，菜单隐藏不代替接口校验。

证据目前为文本，不支持附件、自动校准或对外出具证书。现场隔离、系统外记录核查和实际产品处置由责任人员执行。
