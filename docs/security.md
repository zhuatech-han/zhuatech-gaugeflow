# GaugeFlow · 安全与授权边界

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 身份与权限

密码BCrypt12轮，无固定默认密码；至少12位、大写/小写/数字，UTF-8最多72字节。会话HttpOnly、SameSite Strict，30分钟超时；HTTPS入口使用COOKIE_SECURE=true。密码重置和停用撤销旧会话，角色权限每次服务端核对。

写接口CSRF保护，同源部署，无宽松CORS。账号存在性不从登录错误泄露，失败按来源及账号限流。全部核心资源按部门隔离，管理目录仅全范围管理员。报告提交者不可自审，事件创建者及评估者不可复核该事件；管理员无自审例外。

## 数据与记录

业务事务同时追加审计和状态事件，应用不提供修改事件接口。这不是密码学防篡改，数据库管理员有修改能力。SQL条件参数绑定，实体与排序由固定代码选择，导出复用数据范围。文本显示使用Vue转义，不渲染用户HTML。

不支持文件上传，证据为文本引用。日志与导出不插入品牌广告。不得将客户信息、密码、Cookie、会话、生产配置和未脱敏日志提交Git；.env与.smoke-state.json忽略。发布扫描只检查常见模式，不能替代人工差异审查。

## 部署

默认只绑定127.0.0.1，数据库与后端不开放宿主端口；容器前后端非root。对外部署需HTTPS入口、网络访问控制、备份、容量及业务验证。多实例会话、分布式限流、多租户与身份提供方集成尚未实现。
