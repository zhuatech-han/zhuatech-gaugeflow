# GaugeFlow · 架构与事务

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 服务结构

Spring Security保护会话及CSRF。AuthController处理登录和本人密码，AccessService每次读取数据库角色与账号状态。AdminService维护系统目录。GaugeService处理量具、报告、使用、影响评估和状态流转。GaugePolicy统一上海日期和报告次序。

Nginx同源代理/api，MySQL保存业务，Flyway管理V1/V2。会话保存在后端内存，重启需重新登录。

## 并发与重试

全部写操作先锁总部department#1行，锁后刷新当前账号与角色，READ COMMITTED事务再检查对象范围、版本和状态。使用登记与失败报告提交因此不会交错遗漏：使用先提交会进入快照，冻结先提交则使用被拒绝。影响记录更新同时递增父事件revision，提交需基于最新事件版本。

业务命令requestKey为UUID，SHA-256绑定账号、接口动作、对象及完整载荷，重复请求精确匹配才返回成功；不同内容重用返回409。新台账及管理目录依赖唯一约束与客户端禁用重复提交，没有通用跨接口幂等保障。

## 查询与限制

核心列表数据库内按部门、文本和状态过滤，20条默认分页，最大100；排序仅支持最早或最近登记。目录、下拉、仪表盘和工作台上限10000，统计超限返回REPORT_LIMIT。明细历史与事件关联读取没有分页，适合小规模学习部署；生产大数据使用需要补充归档与分页。全局行锁串行处理写入，没有高并发能力承诺。

## 业务边界

报告事实不可编辑。拒绝不删除原始事实。追溯快照从上次合格时间至失败登记时间，包含冲销记录，供人工评估。校准审核只记录人工报告结论，不计算测量不确定度或推断产品合格。事件关闭与重新校准是恢复使用的两个独立前提。

首版部门为数据范围，不等同租户隔离。角色允许ALL或DEPARTMENT，系统目录要求ALL。原账号引用受外键保护；历史显示名来自当前账号目录，部门外名字显示编号。
